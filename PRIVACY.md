# Приватность Заставы

Этот документ описывает, какие данные Застава отправляет во внешние сети, что видит её локальный шлюз и что хранится на вашем компьютере. Версия: 2.1.0. Список составлен по исходному коду репозитория; при изменении кода список нужно обновлять.

---

## 1. Что Застава не делает

* **Не расшифровывает HTTPS.** Застава не устанавливает корневые сертификаты (`Root CA`) в систему. Промпты, ответы моделей, куки, токены и ключи API передаются внутри зашифрованного соединения между вашим компьютером и сервером сервиса.
* **Не имеет собственных серверов.** Застава не отправляет IP-адреса, настройки, журналы или результаты проверок ни на какие серверы разработчиков.
* **Не содержит аналитики.** В зависимостях Rust и npm нет аналитических, трекинговых и диагностических SDK.
* **Не загружает правила из сети.** Таблицы правил (`rules/dangerous_asns.json`, `rules/provider_matrix.json`) встроены в приложение при сборке. Из сети скачивается только публичный список выходов Tor (см. раздел 3): это данные для сверки, а не правила, и в запросе нет ничего о вас.

---

## 2. Что видит локальный шлюз

Шлюз слушает только адрес `127.0.0.1` (порт `8899`, при занятом порте — запасной).

* **HTTPS (`CONNECT`).** Шлюз видит домен и порт назначения, но не содержимое.
* **HTTP без шифрования.** Такой запрос шлюз пересылает, поэтому видит его целиком. Для сервисов ИИ запросы по HTTP шлюз не пересылает и отклоняет.
* **Цели.** Туннели разрешены только на порты `80`, `443` и `8443`. Адреса `localhost`, внутренние имена и приватные диапазоны IP отклоняются.

---

## 3. Внешние запросы приложения

Ниже перечислено всё, что Застава отправляет во внешние сети. Все адреса есть в исходном коде; путь в скобках указывает, где они заданы.

| Назначение | Куда уходит запрос | Когда | Что становится известно получателю |
| :--- | :--- | :--- | :--- |
| **Определение IP, страны и провайдера** | `https://ipwho.is/`, `https://ipinfo.io/json`, `https://freeipapi.com/api/json`, `https://1.1.1.1/cdn-cgi/trace` (`auditor/network.rs`) | При проверках и при смене сети | Ваш адрес выхода в сеть (как адрес подключения) |
| **Проверка реального выхода к сервису ИИ** | `https://claude.ai/cdn-cgi/trace` (Claude), `https://chatgpt.com/cdn-cgi/trace` (ChatGPT), `https://ipinfo.io/json` (Gemini — только при привязанном маршруте) (`auditor/network.rs`) | При проверках провайдера (через привязанный маршрут или напрямую); для Gemini без отдельного маршрута запрос не отправляется | Адрес выхода в сеть или адрес выхода привязанного маршрута (обычный HTTPS-запрос GET с `User-Agent: Zastava/1.0`, без куки, токенов и промптов) |
| **Фоновый контроль маршрута** | `https://1.1.1.1/cdn-cgi/trace`, резерв `https://api.ipify.org` (`proxy/guard.rs`) | Пока хотя бы один сервис ИИ работает без выделенного маршрута: примерно раз в секунду | Ваш адрес выхода в сеть |
| **Проверка DNS-резолвера (`whoami`)** | DNS-запросы `whoami.akamai.net` (A) и `o-o.myaddr.l.google.com` (TXT) через системный резолвер (`auditor/probes/whoami.rs`) | При проверках | Адрес вашего DNS-резолвера (Akamai и Google видят его как источник запроса) |
| **Страна DNS-резолвера** | `https://ipwho.is/{ip}`, `https://ipinfo.io/{ip}/json`, `https://freeipapi.com/api/json/{ip}` (`auditor/probes/whoami.rs`) | При проверках | Адрес вашего DNS-резолвера |
| **Спам-базы (DNSBL)** | DNS-запросы в зоны `zen.spamhaus.org`, `dnsbl.dronebl.org`, `b.barracudacentral.org`, `bl.spamcop.net`, `dnsbl-1.uceprotect.net` через системный резолвер (`rules/dangerous_asns.json`, `auditor/dnsbl.rs`) | При проверках | Адрес выхода в сеть, записанный в имени запроса (в обратном порядке); контрольный адрес `127.0.0.2` |
| **Список выходов Tor** | `https://check.torproject.org/torbulkexitlist` (`auditor/ip_type.rs`) | При проверке типа адреса: список скачивается целиком и кэшируется на 6 часов (дальше при проверках не запрашивается); только при выходе по IPv4 | Обычный запрос HTTPS к `check.torproject.org`: сервер видит адрес, с которого пришёл запрос, как у любого сайта. Ваш выходной IP в запросе не передаётся: сверка с загруженным списком идёт на вашем компьютере. Запрос идёт напрямую с вашего компьютера, а не через VPN-маршрут |
| **UDP / STUN** | `stun.cloudflare.com:3478`, `stun.l.google.com:19302` по UDP (`auditor/probes/stun.rs`) | При проверках | Адрес, с которого ушёл UDP-пакет (ваш адрес выхода по UDP) |
| **Обновления** | `https://github.com/kingbest1195/ai-antiban/releases/latest/download/latest.json` (`tauri.conf.json`, `updater/mod.rs`); пакет скачивается только при установке, которую вы запустили | Через 20 секунд после запуска и далее раз в час, если включены автообновления | Обычный запрос HTTPS к GitHub |
| **Проверка карты (BIN)** | `https://data.handyapi.com/bin/{первые 6 цифр}` (`bin_checker/mod.rs`) | Только если вы сами запросили проверку и локальные правила не дали ответа | Первые 6 цифр номера карты (BIN) |

Что не отправляется ни в один из этих запросов: полный номер карты, срок действия, имя держателя, CVV, промпты, ответы моделей, куки и ключи маршрутов.

**Трафик, который вы направили через шлюз** (например, `npm`, `brew`, `git` в режиме «Глобальный перехват терминала»), Застава не проверяет и не читает. Он уходит на адреса назначения напрямую или через ваш внешний VPN или прокси, Застава не добавляет к нему сторонних адресов. Имена последних таких хостов (до 20 событий) хранятся только в памяти приложения и пропадают при выходе.

**Запросы к сервисам ИИ** (Claude, ChatGPT, Gemini и ваши дополнительные домены) уходят на эти сервисы через выбранный вами маршрут: прямой выход или ваш ключ `zastava://` или прокси.

## 4. Что хранится на вашем компьютере

Все данные лежат в папке данных приложения:

* macOS: `~/Library/Application Support/io.zastava.desktop/`
* Windows: `%APPDATA%\io.zastava.desktop\`

В этой папке:

* **`state.json`** — настройки, список маршрутов и сохранённые в нём ключи `zastava://` и пароли прокси (в открытом виде; файл создаётся с правами `0600` на Unix) и историю внешних IP-адресов. Пароли и ключи скрыты в интерфейсе и в журнале событий, но в файле хранятся как есть.
* **`ownership/journal.json`** — журнал владения: исходные значения настроек, которые изменила Застава, чтобы вернуть их.

Чтобы удалить эти данные, сначала выйдите из Заставы: при выходе она возвращает изменённые настройки. Удаление журнала до этого может оставить изменённые настройки без автоматического возврата.

---

## 5. Как проверить это самостоятельно

* Адреса внешних запросов: `src-tauri/src/auditor/`, `src-tauri/src/proxy/guard.rs`, `src-tauri/src/bin_checker/mod.rs`, `src-tauri/tauri.conf.json`, `src-tauri/src/proxy/transit.rs`.
* Поиск по репозиторию: `grep -rn "https://" src-tauri/src` и `grep -rn "\.zshenv\|launchctl" src-tauri/src`.
* Сеть при работе приложения можно посмотреть системными средствами (например, Little Snitch, `nettop`, брандмауэр Windows).
